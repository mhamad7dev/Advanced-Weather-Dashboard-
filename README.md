# 🌤️ Weather Dashboard Pro | لوحة الطقس المتطورة

> لوحة تحكم ذكية لعرض الطقس وحالة الجودة الهوائية بتصميم متطور يعتمد على تقنية الـ **Glassmorphism** ومؤثرات البصريات المستقبلية.

---

## ✨ المميزات الرئيسية (Features)

* **🌐 بحث عالمي ذكي:** إمكانية البحث الفوري عن أي مدينة حول العالم باستخدام محرك `GeoCoding API` المتطور.
* **📍 تحديد الموقع الجغرافي تلقائياً:** زر مخصص لجلب طقس موقعك الحالي فوراً عبر `Geolocation API`.
* **🌡️ تحويل الوحدات الديناميكي:** إمكانية التبديل الفوري بين درجتي الحرارة مئوية (°C) وفهرنهايت (°F).
* **📊 توقعات ساعية تفاعلية:** رسم بياني متوهج (Interactive Gradient Chart) يعرض تقلبات درجات الحرارة خلال الـ 24 ساعة القادمة باستخدام مكتبة `Chart.js`.
* **☀️ مسار وتوقيت الشمس:** عداد بصري يوضح حركة الشروق والغروب وموقع الشمس الحالي بدقة.
* **💨 مؤشر جودة الهواء (AQI):** عداد دائري تفصيلي مع قراءات دقيقة للملوثات الرئيسية ($PM_{2.5}, PM_{10}, O_3, NO_2$).
* **📅 توقعات أسبوعية متقدمة:** بطاقات طقس تفصيلية للأيام القادمة تظهر حالة الجو ودرجات الحرارة العظمى والصغرى.
* **📱 تصميم متجاوب (Fully Responsive):** متوافق كلياً مع كافة الشاشات (الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

تم بناء المشروع بأحدث التقنيات وبأكواد نظيفة وخفيفة تعتمد على المعايير القياسية دون الحاجة لأي مكتبات معقدة:

* **HTML5:** الهيكل الأساسي والمنظم للصفحة (`Semantic HTML`).
* **CSS3 (Modern & Glassmorphism):** 
  * استخدام `Flexbox` و `CSS Grid` لتوزيع العناصر.
  * تطبيق تأثيرات `backdrop-filter` للزجاج المعتم.
  * خلفيات متوهجة متحركة (`Glowing Orbs`) لتجربة بصرية فريدة.
* **JavaScript (ES6+):**
  * التعامل مع `Async/Await` لجلب البيانات من الـ APIs الخارجية.
  * إدارة الحالة والتحديث الفوري للواجهة (`DOM Manipulation`).
* **Chart.js:** لرسوم البياني الساعي المتطور.
* **Font Awesome:** لأيقونات الطقس والمؤشرات الاحترافية.
* **Open-Meteo API:** مصدر البيانات المناخية وجودة الهواء المجاني والموثوق.
